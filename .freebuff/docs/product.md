# Nexus Map - AI Powered Smart Tourism Ecosystem

## Current Architecture
- Next.js App Router frontend with TypeScript
- Express backend server (port 5000)
- Supabase for auth + database
- NextAuth.js for authentication
- IndexedDB (offlineDb) for offline-first data
- Drizzle ORM for DB schema
- TomTom API for maps/routing/traffic
- OpenAI integration for AI features
- PWA with service worker for offline
- Three.js 3D globe on hero
- Framer Motion for animations
